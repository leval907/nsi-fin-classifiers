## Цель

Каждая из 7 баз 1С группы компаний должна быть привязана к двум мастер-справочникам:

-  **Мастер ДДС** (`fin_items` или `eco_items`) -- для отчёта о движении денежных средств

-  **Мастер затрат** (`cost_items_clean`) -- для P&L и управленческого учёта затрат

Маппинг по каждому направлению ведётся независимо. Связь между мастером ДДС и мастером затрат не строится.

### Задачи

#### 1\. Закрыть пробелы в маппинге ДДС ⚠️

12 бухгалтерских статей (`buch_items`) не имеют ни одной записи в `buh_to_eco_map`. Для каждой найти соответствующую статью мастера ДДС и добавить маппинг.

#### 2\. Заполнить классификацию P&L в мастере затрат 🔲

Для всех 150 статей `cost_items_clean` заполнить поля:

-  `cost_type` -- FIX / VAR

-  `pl_block` -- OPEX_FIX / OPEX_VAR / DEPR / TAX

-  `pl_category` -- детальная категория P&L

#### 3\. Построить маппинг затрат для каждой базы 🔲

Для каждой из 7 баз 1С сопоставить локальные статьи затрат с `cost_items_clean`.

| База   | Статей затрат | Приоритет |
|--------|---------------|-----------|
| КБУ    | 225           | Высокий   |
| РС     | 221           | Высокий   |
| ГП     | 208           | Высокий   |
| Глоб   | 122           | Средний   |
| Ворпал | 73            | Средний   |
| БОС    | 36            | Средний   |
| Зорг   | 20            | Низкий    |

#### 4\. Построить маппинг ДДС для 6 баз вне КБУ 🔲

КБУ уже смэплена. Для остальных 6 баз сопоставить локальные статьи ДДС с мастером ДДС через `buh_to_eco_map`.

Итоговая схема

```
1С каждой базы
    │
    ├── Статья ДДС (локальный справочник базы)
    │       │
    │       └── buh_to_eco_map
    │               │
    │               ▼
    │           Мастер ДДС (fin_items / eco_items)
    │               └── Отчёт ДДС, БДДС, план-факт
    │
    └── Статья затрат (локальный справочник базы)
            │
            └── Маппинг затрат базы → cost_items_clean
                    │
                    ▼
                Мастер затрат (cost_items_clean)
                    └── P&L, OPEX-отчёт, план-факт затрат
```
