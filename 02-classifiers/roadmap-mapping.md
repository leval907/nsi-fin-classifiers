## Цель

Все справочники группы компаний должны быть привязаны к единому мастер-классификатору `eco_items`.
Это позволит при трансляции любого факта из 1С автоматически получать:
- строку ДДС (операционная / финансовая / инвестиционная деятельность)
- строку P&L (статья затрат, блок, категория)
- признак контура (внешний EXT / внутригрупповой VGO)

## Задачи по порядку

### 1. Закрыть пробелы в buh_to_eco_map ⚠️

12 бухгалтерских статей (`buch_items`) не имеют ни одной записи в `buh_to_eco_map`.
Нужно для каждой найти соответствующую ECO-статью и добавить маппинг.

### 2. Добавить признак контура VGO в buh_to_eco_map 🔲

Сейчас в `buh_to_eco_map` нет поля для признака внутригрупповой операции.
Добавить поле `VGO` (Single Line Text, значения `EXT` / `VGO`) —
аналогично тому, как это уже сделано в `fin_items.VGO`.

### 3. Заполнить классификацию P&L в cost_items_clean 🔲

Перед построением маппинга нужно заполнить поля классификации для всех 150 статей:
- `cost_type` — FIX / VAR (постоянные / переменные)
- `pl_block` — OPEX_FIX / OPEX_VAR / DEPR / TAX
- `pl_category` — детальная категория P&L

### 4. Построить маппинг cost_items_clean → eco_items 🔲

Каждая статья затрат (`cost_items_clean`) должна быть сопоставлена с ECO-статьёй.
По онтологии статьи затрат используют `BB=00` (начисление без движения денег).

Механизм: отдельная таблица маппинга или поле-ссылка в `cost_items_clean`.
