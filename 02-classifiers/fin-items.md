## Примечания

### Структура кода FIN_Code: `AA-BBGGII`

-  **AA** -- вид деятельности: `01` = Операционная, `02` = Финансовая, `03` = Инвестиционная

-  **BB** -- направление потока (специфика fin_items):

   -  `11` -- ПРИТОК операционный

   -  `12` -- ОТТОК операционный

   -  `21` -- ПРИТОК финансовый

   -  `22` -- ОТТОК финансовый

   -  `31` -- ПРИТОК инвестиционный

   -  `32` -- ОТТОК инвестиционный

-  **GG** -- группа статей (01–18 в зависимости от вида деятельности)

-  **II** -- порядковый номер статьи внутри группы

### Отличие от eco_items

В `eco_items` используется унифицированная нумерация BB: `11`=приток, `12`=отток для всех трёх видов деятельности. Трансформация: `02-21xxxx` -> `02-11xxxx`, `02-22xxxx` -> `02-12xxxx`, `03-31xxxx` -> `03-11xxxx`, `03-32xxxx` -> `03-12xxxx`.

### Пропущенные номера в группах

В некоторых группах есть пропуски в нумерации (например, GG=05 начинается с 02, GG=06 нет 02, GG=14 нет 06, GG=17 нет 05, GG=32 нет 07/08) -- зарезервированы для будущих статей.

### Статьи ВГО (внутригрупповые обороты)

Статьи с суффиксом «ВГО» и признаком `VGO = "ВГО"` используются для учёта внутригрупповых расчётов. Всего ВГО-статей: 13 (операционный приток) + 12 (операционный отток) + 4 (финансовые) + 7 (инвестиционные) = **36 статей**.
