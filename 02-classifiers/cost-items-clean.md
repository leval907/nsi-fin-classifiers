## Контекст: два справочника в группе компаний

В ходе работы обнаружилось, что в группе компаний исторически существуют **два разных справочника статей затрат**, которые формировались независимо разными юрлицами:

| Таблица            | Записей | Происхождение                                                                                            | Статус         |
|--------------------|---------|----------------------------------------------------------------------------------------------------------|----------------|
| `cost_items`       | 167     | Собирался вручную, первая версия. 65 записей без кода -- народные названия, дубли, устаревшие статьи.    | Архив          |
| `cost_items_2`     | 214     | Сформирован с нуля из Excel `статьи затрат_2.xlsx`. Структурированнее, есть `nu_type`, коды проставлены. | Исходник       |
| `cost_items_clean` | 150     | Очищенная версия `cost_items_2` -- целевой рабочий справочник.                                           | **Актуальный** |

Справочники **не совпадают** по составу: 16 статей есть только в старом, 45 -- только в новом. Это отражает реальность: разные юрлица группы вели учёт независимо.

`**cost_items_clean**` **-- целевой единый справочник группы.** `cost_items` остаётся как исторический архив.

## Что сделано для получения cost_items_clean

1. Бухгалтер разметила записи на удаление в `cost_items_2` -- поле `Delete = true`

2. Создан дубликат `cost_items_clean` (NocoDB ID: `m3j58awqn4dk16w`)

3. Удалены 64 помеченные записи

**Удалённые категории:**

-  Проектные коды -- инвестиционные статьи, не OPEX

-  ЕНВД-варианты -- дубли по НДФЛ/взносам для спецрежима

-  Разовые/нетипичные услуги -- уборка снега, 3D-моделирование, флористика

-  Статьи НЕ НУ без систематики

-  Строительные статьи -- расходы на документацию, испытание грунтов

-  Списание НДС -- технические бухгалтерские проводки
