## Назначение документа

Документ предназначен для ИТ-специалиста, выполняющего загрузку справочников финансовых статей в систему 1С:НСИ. Описывает состав, назначение и ключевые характеристики каждого справочника.

---

## 1. Справочник финансовых статей ДДС (fin_items)

**Назначение:** управленческий классификатор движения денежных средств. Используется в бюджетировании, финансовом анализе, консолидированной отчётности группы компаний.

**Количество записей:** 195

**Иерархия:** 4 уровня + признак контура

```
Вид деятельности (AA)
  └── Направление потока (BB)
        └── Группа статей (GG)
              └── Конкретная статья (II)
                    └── Контур консолидации (VG: EXT / VGO)
```

**Состав по разделам:**

| Раздел                  | Статей |
|-------------------------|--------|
| Операционная деятельность | 128  |
| Финансовая деятельность   | 27   |
| Инвестиционная деятельность | 40 |
| **ИТОГО**               | **195** |

**Ключевые поля:**
- `fin_code` — уникальный код статьи в формате `AA-BBGGII` (например, `01-120201`)
- `fin_name` — наименование статьи
- `activity_type` — вид деятельности: Операционная / Финансовая / Инвестиционная
- `flow_direction` — направление: Приток / Отток
- `group_code` — код группы (AA-BBGG)
- `vg_type` — признак контура: EXT (внешний) / VGO (внутригрупповой)

**Целевой справочник в 1С:НСИ:** «Статьи движения денежных средств» (управленческий)

---

## 2. Бухгалтерский справочник ДДС (buch_items)

**Назначение:** регламентированный классификатор ДДС по РСБУ. Соответствует форме отчёта о движении денежных средств (ОДДС). Используется в бухгалтерском учёте и официальной отчётности.

**Количество записей:** 52

**Иерархия:** 3 уровня

```
Вид деятельности (100/300/500 — притоки, 200/400/600 — оттоки)
  └── Группа (110, 120, 210, 220, 230, 240...)
        └── Статья (111, 112, 121...)
```

**Состав по разделам:**

| Раздел                    | Статей |
|---------------------------|--------|
| Операционная деятельность | 28     |
| Инвестиционная деятельность | 12   |
| Финансовая деятельность   | 12     |
| **ИТОГО**                 | **52** |

**Ключевые поля:**
- `buch_code` — трёхзначный числовой код статьи (111, 212, 401...)
- `buch_name` — наименование статьи
- `activity_type` — вид деятельности
- `flow_direction` — направление: Приток / Отток
- `group_code` — код группы (трёхзначный)

**Целевой справочник в 1С:НСИ:** «Статьи движения денежных средств» (регламентированный / РСБУ)

## 3. Справочник статей затрат (cost_items)

**Назначение:** классификатор операционных расходов для управленческого отчёта о прибылях и убытках (P&L). Используется при планировании и анализе затрат по подразделениям.

**Количество записей:** 167 (из которых 65 без кода — требуют инвентаризации)

**Иерархия:** 2 уровня

```
Тематическая группа (по сотням: 100–1000+)
  └── Статья затрат (числовой код: 102, 201, 702...)
```

**Состав по группам:**

| Группа                      | Диапазон | Статей |
|-----------------------------|----------|--------|
| Амортизация                 | 100–199  | 4      |
| Аренда и лизинг             | 200–299  | 8      |
| Налоги имущественные        | 300–399  | 4      |
| ТМЦ, материалы, ГСМ         | 400–499  | 8      |
| Прочие общехоз. расходы     | 500–599  | 8      |
| НЕ НУ расходы               | 600–699  | 16     |
| Персонал                    | 700–799  | 10     |
| Производственные расходы    | 800–899  | 8      |
| Услуги прочие               | 900–999  | 32     |
| Прочие (1000+)              | 1000+    | 4      |
| Без кода (некласс.)         | —        | 65     |
| **ИТОГО**                   |          | **167** |

**Ключевые поля:**
- `cost_item_code` — числовой код статьи (102–1016, у 65 записей NULL)
- `cost_item_name` — наименование статьи затрат
- `cost_group_code` — код группы (100, 200, ... 1000)
- `cost_type` — тип: FIX (постоянные) / VAR (переменные)
- `pl_block` — блок P&L: OPEX_FIX / OPEX_VAR / DEPR / TAX
- `pl_category` — категория P&L: LABOR_DIRECT, FIX_RENT, FIX_IT, TAX_PROPERTY и др.

**Целевой справочник в 1С:НСИ:** «Статьи затрат»

## 4. Таблица маппинга BUH → ECO (buh_to_eco_map)

**Назначение:** таблица соответствия между бухгалтерскими статьями ДДС (buch_items) и экономическими статьями (eco_items). Служит правилом автоматического перевода факта из бухгалтерского учёта в управленческий.

**Количество записей:** 280

**Структура связи:**

```
buch_items (52 статьи)
      ↓ одна BUH → много ECO
eco_items (242 статьи)
```

**Ключевые поля:**
- `buch_code` — ссылка на статью buch_items
- `eco_code` — ссылка на статью eco_items
- `mapping_rule` — описание правила перекодировки (при наличии)
- `is_active` — признак активности правила

**Целевой объект в 1С:НСИ:** «Правила соответствия статей ДДС» или аналогичный механизм трансляции кодов

---

## Порядок загрузки в 1С:НСИ

Рекомендуемая последовательность загрузки справочников:

1. **buch_items** — загружается первым, так как является корневым (агрегирующим) уровнем
2. **fin_items** — загружается вторым, ссылается на buch_items через маппинг
3. **cost_items** — загружается независимо, не связан с fin_items напрямую
4. **buh_to_eco_map** — загружается последним, требует наличия buch_items и eco_items

Для загрузки используйте Excel-выгрузку из NocoDB (файл прилагается отдельно) или JSON-экспорт через REST API.

По всем вопросам по структуре справочников обращайтесь в финансово-экономическую службу.
