## Назначение документа

Документ предназначен для ИТ-специалиста, выполняющего загрузку справочников финансовых статей в систему 1С:НСИ. Описывает состав, назначение и ключевые характеристики каждого справочника.

---

В 1С:НСИ загружается один из двух вариантов мастера ДДС -- `fin_items` или `eco_items` -- по решению методолога (Юлия Владимировна).

---

### 1\. Управленческий справочник ДДС (fin_items)

**Назначение:** управленческий классификатор движения денежных средств из 1С:УХ. Используется в бюджетировании, финансовом анализе и консолидированной отчётности холдинга.

**Количество записей:** 195

**Иерархия:** 4 уровня + признак контура

```
Вид деятельности (AA)
  └── Направление потока (BB)
        └── Группа статей (GG)
              └── Конкретная статья (II)
                    └── Контур консолидации (VG: EXT / VGO)
```

**Состав по разделам:**

| Раздел                      | Статей  |
|-----------------------------|---------|
| Операционная деятельность   | 128     |
| Финансовая деятельность     | 27      |
| Инвестиционная деятельность | 40      |
| **ИТОГО**                   | **195** |

**Ключевые поля:**

-  `fin_code` -- уникальный код статьи в формате `AA-BBGGII` (например, `01-120201`)

-  `fin_name` -- наименование статьи

-  `activity_type` -- вид деятельности: Операционная / Финансовая / Инвестиционная

-  `flow_direction` -- направление: Приток / Отток

-  `group_code` -- код группы (AA-BBGG)

-  `vg_type` -- признак контура: EXT (внешний) / VGO (внутригрупповой)

-  `is_active` -- признак активности статьи

**Альтернатива:** `eco_items` (172 статьи) -- то же содержание, ВГО как атрибут а не отдельные строки, добавлена иерархия узлов L1–L3. Загружается вместо `fin_items` -- не вместе с ним.

**Целевой справочник в 1С:НСИ:** «Статьи движения денежных средств» (управленческий)

---

### 2\. Бухгалтерский справочник ДДС (buch_items)

**Назначение:** регламентированный классификатор ДДС по РСБУ из КБУ. Является мастером бухгалтерского уровня -- все 6 бухгалтерских баз группы приводятся к этим 52 статьям. Соответствует форме ОДДС.

**Количество записей:** 52

**Иерархия:** 3 уровня

```
Вид деятельности (100/300/500 — притоки, 200/400/600 — оттоки)
  └── Группа (110, 120, 210, 220, 230, 240...)
        └── Статья (111, 112, 121...)
```

**Состав по разделам:**

| Раздел                      | Статей |
|-----------------------------|--------|
| Операционная деятельность   | 28     |
| Инвестиционная деятельность | 12     |
| Финансовая деятельность     | 12     |
| **ИТОГО**                   | **52** |

**Ключевые поля:**

-  `buch_code` -- трёхзначный числовой код статьи (111, 212, 401...)

-  `buch_name` -- наименование статьи

-  `activity_type` -- вид деятельности

-  `flow_direction` -- направление: Приток / Отток

-  `group_code` -- код группы (трёхзначный)

-  `is_active` -- признак активности

**Целевой справочник в 1С:НСИ:** «Статьи движения денежных средств» (регламентированный / РСБУ)

---

### 3\. Справочник статей затрат (cost_items_clean)

**Назначение:** мастер-классификатор затрат для управленческого P&L из КБУ. Охватывает операционные и капитальные расходы. Является эталоном -- все 6 бухгалтерских баз приводятся к этим 150 статьям.

**Количество записей:** 150

**Иерархия:** 2 уровня

```
Тематическая группа (по сотням: 100–1000)
  └── Статья затрат (числовой код: 101, 201, 702...)
```

**Состав по группам:**

| Группа                          | Диапазон  | Статей  | Тип   |
|---------------------------------|-----------|---------|-------|
| Амортизация                     | 100–199   | 5       | OPEX  |
| Аренда и лизинг                 | 200–299   | 10      | OPEX  |
| Налоги и сборы                  | 300–399   | 7       | OPEX  |
| ТМЦ и материальные расходы      | 400–499   | 14      | OPEX  |
| Прочие производственные расходы | 500–599   | 12      | OPEX  |
| Расходы НЕ НУ                   | 600–699   | 27      | OPEX  |
| Оплата труда и взносы           | 700–799   | 11      | OPEX  |
| Коммунальные и эксплуатационные | 800–899   | 11      | OPEX  |
| Прочие услуги                   | 900–999   | 37      | OPEX  |
| Капитальные затраты             | 1000–1099 | 16      | CAPEX |
| **ИТОГО**                       |           | **150** |       |

**Ключевые поля:**

-  `cost_item_code` -- числовой код статьи

-  `cost_item_name` -- наименование статьи затрат

-  `cost_group_code` -- код группы (100, 200, ... 1000)

-  `cost_group_name` -- наименование группы

-  `cost_type` -- тип: FIX (постоянные) / VAR (переменные)

-  `pl_block` -- блок P&L: OPEX_FIX / OPEX_VAR / DEPR / TAX

-  `pl_category` -- категория P&L

-  `nu_type` -- признак налогового учёта

-  `is_active` -- признак активности

**Важно:** группа 1000 «Капитальные затраты» (16 статей) -- это CAPEX, статьи **не входят в P&L**. Они используются на счёте 08 в связке со справочниками Проектов и Объектов из 1С:УХ.

**Целевой справочник в 1С:НСИ:** «Статьи затрат»

---

### 4\. Таблица маппинга BUH -> FIN (buh_to_eco_map)

**Назначение:** таблица соответствия между бухгалтерскими статьями ДДС (`buch_items`) и управленческими статьями ДДС (`fin_items` / `eco_items`). Реализована централизованно ФЭС. Бухгалтерские базы с этой таблицей не работают напрямую.

**Количество записей:** 280

**Структура связи:**

```
buch_items (52 статьи — укрупнённый уровень РСБУ)
      │  одна BUH → несколько FIN
      ▼
fin_items / eco_items (195 / 172 статьи — детальный управленческий уровень)
```

**Ключевые поля:**

-  `buch_code` -- ссылка на статью `buch_items`

-  `eco_code` -- ссылка на статью `fin_items` / `eco_items`

-  `is_active` -- признак активности правила

**Текущее покрытие:** 40 из 52 статей `buch_items` имеют маппинг. 12 статей в работе.

**Целевой объект в 1С:НСИ:** «Правила соответствия статей ДДС»

---

Порядок загрузки в 1С:НСИ

Рекомендуемая последовательность:

1. **buch_items** (52 записи) -- загружается первым, корневой уровень бух.ДДС

2. **fin_items** или **eco_items** (195 / 172 записи) -- управленческий уровень ДДС, выбор одного варианта

3. **buh_to_eco_map** (280 записей) -- правила соответствия, требует наличия обоих справочников ДДС

4. **cost_items_clean** (150 записей) -- загружается независимо, не связан с ДДС

Для загрузки используйте Excel-выгрузку из NocoDB или JSON-экспорт через REST API.

По всем вопросам по структуре справочников обращайтесь в финансово-экономическую службу (ФЭС).
