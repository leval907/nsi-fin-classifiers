## Цель

Подготовить и передать ИТ-подразделению всё необходимое для загрузки справочников в **1С:НСИ** — корпоративную систему нормативно-справочной информации группы компаний.

## Состав пакета

| Документ | Формат | Статус |
|---|---|---|
| Спецификация структуры справочников | Gramax | В работе |
| Описание полей и типов данных | Gramax | В работе |
| Экспорт данных из NocoDB | JSON | Не готово |
| Excel-выгрузка справочников | XLSX | Не готово |
| Инструкция по передаче | Gramax | В работе |

**Критерий готовности:** ИТ-подразделение может загрузить справочники в 1С:НСИ без дополнительных уточнений у методолога.
