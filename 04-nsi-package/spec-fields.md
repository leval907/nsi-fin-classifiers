## Назначение документа

Таблицы полей для каждого справочника: название поля, тип данных, обязательность, описание и пример значения. Предназначено для ИТ-специалиста, выполняющего загрузку в 1С:НСИ или настройку интеграции.

---

## 1. fin_items — Финансовый справочник ДДС

| Поле | Тип | Обязательное | Описание | Пример |
|------|-----|:---:|----------|--------|
| `Id` | Целое число | Да | Системный идентификатор записи (NocoDB) | 1 |
| `fin_code` | Строка | Да | Уникальный код статьи в формате AA-BBGGII | `01-120201` |
| `fin_name` | Строка | Да | Наименование статьи | Оплата труда (в т.ч. алименты, исп. листы) |
| `activity_type` | Строка | Да | Вид деятельности | Операционная |
| `activity_code` | Строка | Да | Код вида деятельности (сегмент AA) | `01` |
| `flow_direction` | Строка | Да | Направление потока | Отток |
| `flow_code` | Строка | Да | Код направления (сегмент BB) | `12` |
| `group_name` | Строка | Да | Наименование группы статей | Выплата заработной платы |
| `group_code` | Строка | Да | Код группы (AA-BBGG) | `01-1202` |
| `item_num` | Строка | Да | Порядковый номер статьи внутри группы (сегмент II) | `01` |
| `vg_type` | Строка | Да | Признак контура: EXT (внешний) / VGO (внутригрупповой) | `EXT` |
| `buch_code` | Строка | Да | Код соответствующей бухгалтерской статьи (BUH) | `222` |
| `description` | Длинный текст | Нет | Примечания и пояснения к статье | — |
| `is_active` | Булево | Да | Признак активности статьи (true = активна) | `true` |

**Количество записей:** 195
**Уникальный ключ:** `fin_code`
**Связи:** `buch_code` → buch_items.buch_code

| `flow_direction` | Строка | Да | Направление потока | Отток |
| `group_code` | Строка | Да | Код группы статей (трёхзначный) | `220` |

## 3. cost_items — Справочник статей затрат

| Поле | Тип | Обязательное | Описание | Пример |
|------|-----|:---:|----------|--------|
| `Id` | Целое число | Да | Системный идентификатор записи (NocoDB) | 1 |
| `cost_item_code` | Целое число | Нет* | Числовой код статьи затрат | `702` |
| `cost_item_name` | Строка | Да | Наименование статьи затрат | Фонд оплаты труда (ФОТ) |
| `cost_group_code` | Целое число | Нет | Код тематической группы (сотни) | `700` |
| `cost_group_name` | Строка | Нет | Наименование группы | Персонал |
| `cost_type` | Строка | Да | Тип затрат: FIX (постоянные) / VAR (переменные) | `FIX` |
| `pl_block` | Строка | Да | Блок в отчёте P&L | `OPEX_FIX` |
| `pl_category` | Строка | Нет | Категория P&L | `LABOR_DIRECT` |
| `nu_type` | Строка | Нет | Налоговый учёт: НУ (принимается) / НЕ НУ (не принимается) | `НУ` |
| `description` | Длинный текст | Нет | Примечания, пояснения | — |
| `is_active` | Булево | Нет | Признак активности | `true` |

**Количество записей:** 167
**Уникальный ключ:** `cost_item_code` (у 65 записей NULL — требует заполнения перед загрузкой в НСИ)

**Допустимые значения pl_block:**
- `OPEX_FIX` — постоянные операционные расходы
- `OPEX_VAR` — переменные операционные расходы
- `DEPR` — амортизация
- `TAX` — налоги

**Допустимые значения pl_category:**
- `LABOR_DIRECT` — прямые затраты на персонал
- `LABOR_TAX` — страховые взносы
- `FIX_RENT` — аренда
- `FIX_IT` — ИТ / инфраструктура
- `FIX_UTILITY` — коммунальные
- `FIX_REPAIR` — ремонт
- `FIX_SECURITY` — охрана
- `TAX_PROPERTY` — имущественные налоги
- `TAX_OTHER` — прочие налоги
- `DEPR_OS` — амортизация ОС
- `OTHER` — прочее

## 4. buh_to_eco_map — Таблица маппинга BUH → ECO

| Поле | Тип | Обязательное | Описание | Пример |
|------|-----|:---:|----------|--------|
| `Id` | Целое число | Да | Системный идентификатор записи (NocoDB) | 1 |
| `buch_code` | Строка | Да | Код бухгалтерской статьи (ссылка на buch_items) | `212` |
| `buch_name` | Строка | Да | Наименование бухгалтерской статьи (для читаемости) | Оплата работ и услуг |
| `eco_code` | Строка | Да | Код экономической статьи (ссылка на eco_items) | `01-120301` |
| `eco_name` | Строка | Да | Наименование экономической статьи | Агентские платежи |
| `activity_type` | Строка | Нет | Вид деятельности (для фильтрации) | Операционная |
| `mapping_comment` | Длинный текст | Нет | Пояснение к правилу маппинга | — |
| `is_active` | Булево | Да | Признак активности правила | `true` |

**Количество записей:** 280
**Ключ:** составной `buch_code` + `eco_code`
**Связи:**
- `buch_code` → buch_items.buch_code
- `eco_code` → eco_items.eco_code

## Примечание по кодировке и форматам

- Все строки: UTF-8
- Булевы значения: `true` / `false` (или 1 / 0 при загрузке через Excel)
- Числовые коды без ведущих нулей, кроме `fin_code` (формат фиксированный: AA-BBGGII)
- Поля с NULL: при загрузке в 1С:НСИ пустые значения передавать как пустую строку `""`, не как `NULL`
- Коды `cost_item_code` с NULL требуют заполнения перед загрузкой — обратитесь в ФЭС за актуальным файлом инвентаризации
