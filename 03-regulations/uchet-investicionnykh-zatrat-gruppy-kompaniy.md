## 1\. Особенности инвестиционного учёта

### 1\.1. Почему инвестиционные затраты выделены отдельно

Инвестиционные затраты **не входят в P&L** (отчёт о прибылях и убытках). Они капитализируются -- формируют стоимость создаваемого актива (здания, оборудования, инфраструктуры) и отражаются на счёте 08 «Вложения во внеоборотные активы» до момента ввода объекта в эксплуатацию.

Это принципиальное отличие от операционных затрат:

| Параметр   | Операционные затраты (OPEX)         | Инвестиционные затраты (CAPEX)        |
|------------|-------------------------------------|---------------------------------------|
| Отражение  | P&L текущего периода                | Счёт 08, затем ОС/НМА                 |
| Справочник | `cost_items_clean` (группы 100–900) | `cost_items_clean` (группа 1000)      |
| Отчёт      | Управленческий P&L                  | Отчёт по инвестпроекту / БДДС инвест. |
| Аналитика  | Подразделение, статья               | Проект, объект, статья                |

### 1\.2. Разрыв между управленческим и бухгалтерским учётом

В инвестиционном контуре существует принципиальный разрыв между двумя моментами:

**Момент платежа** -- деньги ушли подрядчику. Фиксируется в **1С:УХ** как статья инвестиционного ДДС (AA=03). Бюджетное управление ведётся именно здесь.

**Момент начисления затраты** -- подрядчик закрыл работы актом (КС-2, КС-3, УПД). Фиксируется в **1С:Бухгалтерия** проводкой Дт 08 / Кт 60 (76). Между платежом и актом может пройти несколько месяцев.

```
1С:УХ                          1С:Бухгалтерия
  │                                  │
  │  Платёж подрядчику               │  Получен КС-2/КС-3
  │  ДДС: 03-320809                  │  Дт 08 / Кт 60
  │  (статья инвест. оттока)         │  Статья затрат: группа 1000
  │                                  │
  └──────── разрыв во времени ───────┘
                    │
                    ▼
            Заявка в 1С:УХ
         (связующее звено)
```

**Следствие:** в УХ бюджет исполняется по оплате, в бухгалтерии затрата признаётся по акту -- две цифры по одному проекту не совпадают. Заявка является связующим звеном между этими двумя моментами.

## 2\. Справочники инвестиционного контура

### 2\.1. Состав справочников

Для учёта инвестиционных затрат используются следующие справочники:

| Справочник          | Система                                          | Назначение                                                    |
|---------------------|--------------------------------------------------|---------------------------------------------------------------|
| Статьи инвест. ДДС  | 1С:УХ (`fin_items`, AA=03)                       | Классификация денежных потоков по инвестиционной деятельности |
| Статьи затрат CAPEX | 1С:Бухгалтерия (`cost_items_clean`, группа 1000) | Классификация затрат на создание активов                      |
| Проекты             | 1С:УХ                                            | Укрупнённая единица инвестиционной программы                  |
| Объекты             | 1С:УХ (и 1С:Бухгалтерия -- справочно)            | Конкретный строящийся / приобретаемый актив                   |
| Заявки              | 1С:УХ                                            | Связующее звено между ДДС, затратами, проектом и объектом     |

### 2\.2. Иерархия Проект -> Объект

```
Проект
  └── Объект 1
  └── Объект 2
  └── Объект N
```

Один проект содержит один или несколько объектов. Затраты и платежи привязываются на уровне **объекта** -- это минимальная единица аналитики инвестиционного учёта.

**Важно:** справочник Объектов в 1С:УХ и в 1С:Бухгалтерия сейчас различается. Задача синхронизации этих справочников -- отдельный проект, в текущую задачу не входит. Фиксируется как известное ограничение.

### 2\.3. Статьи инвестиционного ДДС (fin_items, AA=03)

Инвестиционный поток в мастере ДДС охватывает 40 статей в трёх блоках:

| Блок                         | Примеры статей                                                         |
|------------------------------|------------------------------------------------------------------------|
| Приобретение ОС и техники    | Лизинг техники, приобретение автотранспорта, приобретение оборудования |
| Строительство (с 01.01.2026) | Инициация проекта, проектирование, СМР, содержание службы заказчика    |
| ВГО инвестиционные           | Приобретение ОС ВГО, технический заказчик ВГО                          |

Полный состав -- в справочнике `fin_items` (AA=03) или `eco_items` (AA=03).

### 2\.4. Статьи инвестиционных затрат (cost_items_clean, группа 1000)

Группа 1000 «Капитальные затраты» содержит 16 статей и охватывает:

-  Строительно-монтажные работы (подрядные и собственными силами)

-  Проектно-изыскательские работы (ПИР)

-  Приобретение оборудования и его монтаж

-  Технический надзор и заказчик

-  Прочие капитальные затраты

-  Проценты по займам в период строительства

Эти статьи используются как субконто на счёте 08 в 1С:Бухгалтерия совместно со справочником Объектов.

## 3\. Заявка как связующее звено

### 3\.1. Роль заявки

Заявка в 1С:УХ является центральным связующим элементом инвестиционного учёта. Она содержит:

-  **Проект** и **Объект** -- к чему относится расход

-  **Статья инвест. ДДС** -- для планирования и контроля денежного потока

-  **Статья затрат CAPEX** -- для контроля стоимости строительства

-  **Сумма и период** -- плановые и фактические

-  **Статус** -- согласована / оплачена / закрыта актом

### 3\.2. Жизненный цикл заявки

```
Заявка создана
    │
    ├── Согласована → бюджет зарезервирован в УХ
    │
    ├── Оплачена → платёж в ДДС (03-32xxxx в fin_items)
    │                отражается в 1С:УХ
    │
    └── Закрыта актом (КС-2/КС-3) → затрата начислена
                                     Дт 08 / Кт 60 в бухгалтерии
                                     Статья группы 1000 + Объект
```

### 3\.3. Что заявка позволяет сделать

-  Сравнить **план по бюджету** (УХ) с **фактом по начислению** (бухгалтерия) в разрезе проекта/объекта

-  Видеть **авансы без закрытых актов** -- деньги ушли, затрата ещё не признана

-  Формировать **отчёт по инвестпроекту** в ФЭД с корректной стоимостью

## 4\. Правила классификации

### 4\.1. Что относится к инвестиционным затратам (CAPEX)

-  Строительно-монтажные работы по созданию нового объекта

-  Проектирование и изыскания под конкретный объект

-  Приобретение оборудования, требующего монтажа

-  Технический надзор в период строительства

-  Расходы на техприсоединение к сетям (электро, газ, вода)

-  Приобретение земельных участков и зданий

-  Проценты по займам, привлечённым под строительство

-  Прочие затраты, формирующие первоначальную стоимость актива

### 4\.2. Что НЕ относится к инвестиционным затратам

-  Текущий ремонт и ТО существующих объектов -> группа 800 (OPEX)

-  Аренда строительной техники для операционных нужд -> группа 200 (OPEX)

-  Охрана готового объекта -> группа 800 (OPEX)

-  Коммунальные платежи за готовый объект -> группа 800 (OPEX)

### 4\.3. Граница капремонт / CAPEX

Капитальный ремонт, улучшающий характеристики объекта и увеличивающий срок его службы -- CAPEX (группа 1000). Текущий ремонт, восстанавливающий исходное состояние -- OPEX (группа 800). В спорных случаях решение принимает ФЭС совместно с главным бухгалтером.

## 5\. Отчётность по инвестиционной деятельности

### 5\.1. Отчёт по инвестпроекту

Формируется ФЭД в разрезе: Проект -> Объект -> Статья затрат группы 1000.

Показывает:

-  Бюджет (план из заявок УХ)

-  Оплачено (факт ДДС из УХ)

-  Начислено (факт по актам из бухгалтерии)

-  Отклонение план/факт

### 5\.2. БДДС инвестиционный

Формируется из `fin_items` (AA=03) в разрезе проектов. Показывает движение денег по инвестиционной деятельности -- отдельно от операционного и финансового потоков.

### 5\.3. Известные ограничения

-  Справочник Объектов в 1С:УХ и 1С:Бухгалтерия сейчас различается -- ручная сверка при подготовке отчётов

-  Момент признания затраты в бухгалтерии (дата акта) может не совпадать с периодом платежа в УХ -- необходима сверка авансов

## 6\. Ответственность

| Процесс                                             | Ответственный                          |
|-----------------------------------------------------|----------------------------------------|
| Ведение справочника Проектов и Объектов в УХ        | ФЭД                                    |
| Ведение статей инвест. ДДС (`fin_items`, AA=03)     | ФЭС                                    |
| Ведение статей затрат CAPEX (группа 1000)           | ФЭС                                    |
| Формирование отчёта по инвестпроекту                | ФЭД                                    |
| Контроль соответствия заявок и актов                | ФЭД + бухгалтерия                      |
| Синхронизация справочника Объектов УХ и бухгалтерии | Отдельная задача, вне текущего проекта |
